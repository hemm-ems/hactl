# Functions that `deadcode -test=false ./cmd/hactl` reports as unreachable from
# the hactl binary and that are accepted, for now, with the reason on the line.
#
# Format: <file> <func>  # <class>: <reason>
# Checked by dev/deadcode-gate.sh, which is part of `make gates` and CI.
#
# Two classes only:
#
#   harness — the function exists to serve a test or a gate and is not part of
#             the product surface. Legitimate; it stays.
#   orphan  — product code with no path from main. Every one of these is a
#             standing defect: the tests below it are green and prove nothing
#             about what a user can do. Wire it or delete it.
#
# Adding a line is a decision, not a formality. Deleting one is always safe:
# the code is in git.

# --- harness -----------------------------------------------------------------
internal/cmd/root.go RunWithOutput            # harness: the entry point every CLI test drives the cobra tree through
internal/cmd/introspect.go LeafCommandPaths   # harness: enumerates the cobra tree for the H-10 command-tree walk
internal/mcpserver/gate.go ClassifiedPaths    # harness: enumerates the write-gate classification for its sweep tests
internal/companion/discovery.go DiscoveryReasons  # harness: the closed set of discovery failure reasons, so H-24's "each reason names its own fix" can be quantified over the set rather than over the reasons somebody remembered; the product handles one reason at a time and never enumerates them

internal/policy/reqmap/rows.go MatchTemplate    # harness: keys a source path built by concatenation by its classifier row, for the H-29 closure gate (internal/surfaceaudit)
internal/policy/reqmap/rows.go Rows             # harness: the classifier's row table, which the H-29 gate holds in lockstep with dev/surfaces/policy.manifest
internal/policy/reqmap/types.go Disposition.String  # harness: names a disposition in the classifier's tests and the gate's reports
internal/policy/applicability.go ApplicableVerbs  # harness: the applicability table exactly at one address, which the D-110 lockstep gates (internal/policy/applicabilitygate) hold against the emitted triples and the manual
