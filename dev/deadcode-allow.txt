# Functions that `deadcode -test=false ./cmd/hactl` reports as unreachable from
# the hactl binary and that are accepted, for now, with the reason on the line.
#
# Format: <file> <func>  # <class>: <reason>
# Checked by dev/deadcode-gate.sh, which is part of `make gates` and CI.
#
# Two classes only:
#
#   harness — the function exists to serve a test or a gate and is not part of
#             the product surface. Legitimate; it stays.
#   orphan  — product code with no path from main. Every one of these is a
#             standing defect: the tests below it are green and prove nothing
#             about what a user can do. Wire it or delete it.
#
# Adding a line is a decision, not a formality. Deleting one is always safe:
# the code is in git.
